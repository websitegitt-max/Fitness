# Fitnex Website Reconstruction (Static HTML Version)

This project is an independently implemented frontend website reconstructing the visual structure of a premium fitness studio. It has been built as a **single, static HTML file** using Tailwind CSS via CDN, making it incredibly lightweight and instantly deployable to platforms like GitHub Pages.

## Features & Compliance
- **Zero Build Step:** 100% standard HTML, runnable instantly in any browser.
- **Tailwind CDN:** Fully responsive and styled using the Tailwind CSS Play CDN.
- **Licensed Assets:** Uses legally distributable Unsplash imagery in place of proprietary photographs.
- **Original Copy:** Uses non-copyrighted placeholder branding and original text.

## How to Host on GitHub Pages
Because this is a static `index.html` file, hosting it is free and takes less than a minute:

1. **Create a Repository:** Go to GitHub and create a new public repository (e.g., `fitnex-website`).
2. **Upload Files:** Upload the `index.html` file provided into the root of this new repository.
3. **Enable GitHub Pages:**
   - Go to your repository's **Settings** tab.
   - Scroll down on the left sidebar and click on **Pages**.
   - Under "Build and deployment" > "Source", select **Deploy from a branch**.
   - Under "Branch", select `main` (or `master`) and keep the folder as `/ (root)`. 
   - Click **Save**.
4. **View your site:** Within a few minutes, your website will be live at `https://<your-username>.github.io/<your-repo-name>/`.
